# Vendor Management System

## Overview

A Power Platform solution designed to streamline vendor onboarding,
approval workflows, document management, and contract tracking.

## Business Problem

Many organizations manage vendor information using spreadsheets and emails,
resulting in approval delays and data inconsistencies.

## Solution

Built using:

- Power Apps
- Dataverse
- Power Automate
- Microsoft 365

## Key Features

- Vendor Registration
- Multi-Level Approval Workflow
- Contract Tracking
- Document Management
- Automated Notifications
